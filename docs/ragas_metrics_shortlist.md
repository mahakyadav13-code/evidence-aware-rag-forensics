# RAGAS Metrics — Shortlist for Evidence-Aware Forensic RAG

| Metric | Priority | Why it matters for forensics |
|---|---|---|
| Faithfulness | Highest | Prevents hallucinated claims — critical for legal admissibility |
| Context Recall | High | Missed evidence = incomplete investigation |
| Context Precision | Medium | Reduces noise, improves investigator trust |
| Answer Relevance | Medium | Keeps generated report on-topic |
